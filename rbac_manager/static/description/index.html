Risk Levels Explained

Every permission is classified by risk level, ensuring appropriate oversight and preventing unauthorized access escalation.

Low

Routine operational permissions that pose minimal risk

View reports, read-only access, basic data entry

Medium

Permissions requiring review before deployment

Create/edit records, generate invoices, manage inventory

High

High-impact actions requiring Super Admin approval

Financial postings, contract approvals, salary modifications

Critical

System-level access excluded from templates entirely

User management, system settings, security configuration

⚠️

Critical Permissions Protection

Critical permissions are completely hidden from role templates and can only be assigned directly by Super Admins. This prevents accidental or malicious privilege escalation through template modification.

🔐 Flexible Permission Management

Need additional permissions beyond the template? Our system offers multiple options:

  • Request by User: Users can request additional permissions that route to Super Admin for approval
  • Direct Assignment: Super Admin can assign extra permissions directly to users when needed
  • Template Exclusions: Remove specific permissions from a template for individual users while keeping the rest
  • Temporary Access: Grant time-limited permissions for special projects or urgent needs

All permission changes are fully logged in the audit trail for compliance tracking.
