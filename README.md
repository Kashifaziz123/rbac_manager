# Odoo Role & Permission Manager (RBAC)

A powerful **RBAC (Role-Based Access Control)** module for Odoo that helps you manage user permissions with **role templates** and **delegated administration**.

## ✨ Features
- Define reusable **role templates** with access rights.
- Assign roles to users with one click.
- Delegate role management to **permission manager**.
- Multi-company support.
- Audit-ready: consistent & secure role definitions.

## 🚀 Benefits
- **Save time** when onboarding new users.
- **Reduce errors** by standardizing permissions.
- **Delegate safely** without losing super admin control.
- Built on **enterprise RBAC standards** (like SAP, Oracle, Microsoft).

## 🔧 Technical Details
- Compatible with Odoo 16/17/18 (Community & Enterprise).
- Module technical name: `rbac_manager`.
